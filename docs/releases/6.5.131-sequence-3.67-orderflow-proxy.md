# Cloud 6.5.131 / Stable 6.4.7 — M1 order-flow proxy telemetry

## Scope

DEMO/PAPER ONLY.

- Cloud: 6.5.131
- Stable package: 6.4.7
- DataBridge: 1.58
- Sequence: 3.67

This release adds an M1 execution-quality observation layer without changing Master Sniper HTF zoning authority, M15 health/invalidation authority, the three model-specific confirmation contracts, or the existing context/grade risk matrix.

## Data-source truth

Deriv XAUUSD is a CFD feed. The Sequence EA does **not** have centralized COMEX bid/ask transaction data and must not represent broker tick volume as true exchange delta.

The new feed is therefore explicitly named:

`CFD_TICK_VOLUME_PROXY`

It derives a closed-M1 pressure proxy from broker tick volume, candle body efficiency and close location. It is research telemetry, not centralized order flow.

## M1 proxy observations

Sequence 3.67 records:

- normalized directional tick-volume pressure ("delta proxy"),
- directional pressure expansion,
- high-activity / low-efficiency rejection as an absorption proxy,
- price-extreme versus pressure divergence,
- a combined directional support score and state.

States are `SUPPORTIVE`, `MIXED`, `CONTRADICTORY`, or an unavailable/disabled state.

## Execution authority

The default is:

`OrderFlowProxyMode=1` — **TELEMETRY ONLY**

At this default, the proxy cannot create a zone, acquire a thesis, change direction, change grade, increase risk, bypass a Model 1/2/3 confirmation, or block an otherwise valid entry. It exists so the validation ledger can accumulate evidence before the proxy is allowed to influence execution.

Optional paper-research modes are available but are not the release default:

- mode 2: veto only a strong proxy contradiction;
- mode 3: require supportive proxy evidence.

Those modes should be promoted only after enough observed samples support doing so.

## Existing model contracts preserved

1. Model 1 — liquidity sweep → closed M1 micro MSS → causal OB/FVG → bounded retest → directional close.
2. Model 2 — valid recent-zone context → closed directional real-body engulfing. No separate Model-1 MSS gate.
3. Model 3 — institutional boundary break → displacement → acceptance → retest → closed directional M1 confirmation. No separate Model-1 MSS gate.

Accepted-zone flips retain their own retest and confirmation contract. The order-flow proxy is evaluated after the model-specific confirmation chain, not as a substitute for it.

## Telemetry and audit

Sequence state, heartbeat, dashboard and `ENTRY_DECISION` audit now expose:

- `orderflow_proxy_mode`
- `orderflow_proxy_feed`
- `orderflow_proxy_state`
- `orderflow_proxy_score`
- `orderflow_proxy_delta_norm`
- `orderflow_proxy_absorption`
- `orderflow_proxy_divergence`
- `orderflow_proxy_expansion`

The dashboard explicitly states that this is a broker CFD tick-volume proxy and **not centralized COMEX bid/ask delta**.

## Future centralized feed

A later research phase may connect COMEX GC/MGC bid/ask trade data as a separate external confirmation source. That would be a distinct data-source contract and must not silently replace or masquerade as the current CFD proxy.
