## Why this release exists

Sequence 3.68 correctly separated the order stop from the remote H4/H1 thesis invalidation boundary, but it still used the generic signal anchor as the execution-stop reference.

The observed SELL proved that this could be too tight: the Model-2 engulfing entry used an anchor-derived stop inside the nearby M1 swing structure and was stopped before the local setup was structurally invalidated.

## Sequence 3.69 stop contract

For every new M1 execution:

- SELL SL = nearest confirmed, still-protected M1 swing high above the actual entry + execution buffer.
- BUY SL = nearest confirmed, still-protected M1 swing low below the actual entry - execution buffer.
- A swing is considered confirmed only when both adjacent M1 candles are already closed before entry.
- A swing is considered protected only if no later closed M1 candle has already breached that level.
- The selected swing must be on the adverse side of the actual entry.
- If no valid protected swing exists inside the execution lookback, the order is not sent. The EA does not invent a tighter stop merely to force minimum RR.

The execution buffer remains the existing maximum of spread allowance, M1 ATR allowance, broker minimum stop distance and the minimum point floor.

## Scope parity

The same protected-swing stop engine is used by:

- P0

- Model 1 — Sniper PD retest

The H4/H1 distal boundary remains thesis invalidation only. A stopped M1 execution does not automatically terminate the acquired HTF thesis.

## RR and risk

Minimum RR remains fail-closed and is calculated only after the protected swing SL is known.

No risk percentages are increased by this release. The campaign/thesis risk cap and split-entry budget remain unchanged.
