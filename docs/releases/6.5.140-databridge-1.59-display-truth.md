# Cloud 6.5.140 / MT5 Stable 6.4.13 — DataBridge 1.59 display truth

## Scope

- Cloud: 6.5.140
- MT5 stable package: 6.4.13
- DataBridge: 1.59
- Sequence EA: 3.72 unchanged
- DEMO / PAPER ONLY

## Display defects addressed

### Historical flip context was phrased like an active execution instruction

DataBridge 1.58 rendered every persisted `FLIP_CONTEXT` zone in the chart status as:

`INVALIDATED BUY -> SELL FLIP CONTEXT | RETEST + M1 REQUIRED`

even when Sequence 3.72 reported `MAP_PLAN` and no accepted flip owned execution.

DataBridge 1.59 reads Sequence's explicit `execution_context_type`, source zone, direction and slot.

When Sequence actually owns an accepted flip, the chart may show:

`ACTIVE ACCEPTED SELL FLIP | F0/FRx | SOURCE <zone> | RETEST + M1 REQUIRED`

When the failed-zone geometry is only retained as context, the chart instead shows:

`HISTORICAL INVALIDATED BUY -> SELL FLIP | CONTEXT ONLY | NO CURRENT M1 AUTHORITY`

The change is display-only. Persisted flip geometry, accepted-invalidation rules and Sequence flip execution logic are unchanged.

### DataBridge startup text carried obsolete Sequence descriptions

The 1.58 source still contained old descriptive references to Sequence 3.47 / 3.48 even though runtime version truth came from the updater and Sequence heartbeat.

DataBridge 1.59 sets its expected Sequence contract to 3.72 and builds the startup message from `TZ_SEQUENCE_EXPECTED`, eliminating hard-coded stale strategy text.

## Invariants

This release does not change:

- Sequence 3.72 source or execution logic;
- P0/R1/R2 campaign rules;
- ownership acquisition/release;
- entry confirmation models;
- accepted-zone flip rules;
- stops, RR, targets or risk;
- position management;
- zone geometry or grading;
- renderer geometry.

The release only corrects DataBridge chart/status wording and expected-version metadata.
