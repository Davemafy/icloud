# Cloud 6.5.101 — Current-State Truth Alignment

Status: DEMO / PAPER ONLY

Stable MT5 package: 6.3.38
- DataBridge 1.55
- DataBridge core 1.32
- Sequence EA 3.45
- Zone renderer V662

## What this corrects

The 6.5.100 execution-separation fix was working, but the live MT5 presentation still had three avoidable truth mismatches:

1. The M1 chart could show `HTF MAP 2` while the dashboard correctly showed one published PRIMARY zone, because DataBridge 1.54 scanned raw `/analysis` text and could count later nested zone identifiers.
2. The M1 chart reduced a finalized `PLAN_WATCH_ONLY` state to the generic text `EXECUTION HOLD`, while the dashboard correctly showed `CLOUD PLAN WATCH ONLY`.
3. Zone labels still printed raw internal states such as `ARMED`, even though the human meaning is `MAP VALID / RETEST PENDING`.

## 6.5.101 behavior

DataBridge now derives the HTF map summary from the canonical `/mt5/zones` renderer feed and counts only `PRIMARY` records. Reserve zones and accepted-invalidated `FLIP_CONTEXT` records remain visible, but they do not inflate the active primary-map count.

The M1 chart now preserves the exact finalized watch-only reason:
`AUTHORITY + PLAN_WATCH_ONLY -> CLOUD PLAN WATCH ONLY`.

Renderer V662 converts internal lifecycle states to human-facing truth:
- `ARMED` -> `MAP VALID / RETEST PENDING`
- `INTERACTING` -> `CONTACTED / M1 PENDING`
- `M1_READY` -> `M1 HANDOFF ACTIVE`
- `FLIP_CONTEXT` -> `FLIP CONTEXT`

No zone geometry, grade, risk, target, invalidation, M1 confirmation, Sequence order logic, or thesis-ownership rule changes.
