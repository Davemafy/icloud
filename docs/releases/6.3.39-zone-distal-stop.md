# MT5 Stable 6.3.39 — first-entry zone-distal stop

Status: DEMO / PAPER ONLY

Components:
- Stable package 6.3.39
- DataBridge 1.56
- Sequence EA 3.46
- Cloud application unchanged

## Live finding

The 29 September SELL campaign on `PZ_H1_SELL_1790600400` exposed a real
risk-placement defect.

Observed execution:
- primary model: ESCAPE_PULLBACK / E0
- SELL entry: about 4152.19
- exit/SL area: about 4154.99
- active SELL tactical core: 4154.32-4157.06
- active full SELL envelope distal high: about 4172.14

The old Sequence implementation calculated the initial stop only from the local
M1 signal anchor plus `SLBufferATR`:

`SELL SL = M1 signal anchor + ATR buffer`

That allowed the first-entry protective stop to sit back inside the same
institutional SELL zone that authorized the thesis. Price could therefore retest
deeper into a still-valid zone and stop the campaign before the institutional
zone itself had failed.

## 3.46 stop contract

For the FIRST entry of an institutional thesis:

- SELL stop = farther of:
  - local M1 structural stop, or
  - full active institutional `zone_high + buffer`
- BUY stop = farther of:
  - local M1 structural stop, or
  - full active institutional `zone_low - buffer`

The buffer is the maximum of:
- 5 broker points
- 1.5x current live spread in price terms
- existing M1 ATR stop buffer
- broker minimum stop distance

The local M1 signal remains the timing engine. It may widen the stop if its
structural extreme is farther away, but it can no longer tighten the FIRST-entry
stop back inside the institutional zone.

Re-entries retain local continuation-structure stops because they occur after the
original institutional risk event and should not automatically inherit a remote
HTF envelope stop.

## Fail-closed RR behavior

The structurally correct stop is calculated BEFORE minimum-RR validation and lot
sizing.

Therefore, if a full-zone stop is too far from the entry relative to the nearest
valid target, the system rejects the entry with `MIN_RR_NOT_MET`. It does not
move the SL inside the zone to manufacture a trade.

For the live example above, a stop beyond the approximately 4172.14 distal zone
edge would have made the 4152.19 -> 4140.67 first objective insufficient for the
configured minimum RR. The correct behavior would therefore have been NO TRADE,
not an artificially tight 4154.99 stop.

## Accepted-zone flip

The same rule applies to the first accepted-zone flip entry (F0). Flip re-entries
retain their local continuation stop.

## Risk sizing

Position size continues to use the actual monetary loss from entry to the final
structural SL via `OrderCalcProfit`. A wider valid stop therefore reduces lot
size. If the risk-sized volume is below broker minimum, the trade remains
fail-closed.
