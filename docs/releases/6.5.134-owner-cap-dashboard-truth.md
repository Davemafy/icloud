## Owner objective-cap repair

The acquired thesis can now re-evaluate its opposing-zone front-run cap on every live plan poll.

If the scheduled analysis originally deferred the cap because Sequence heartbeat truth was temporarily stale, a later fresh Sequence heartbeat with zero open positions allows the same one-way lifecycle cap to be applied without waiting for the next full analysis cycle.

The cap:
- only tightens a flat owner's effective objective/runway;
- never rewrites the frozen owner target ladder;
- never modifies a live position target;
- requires fresh Sequence telemetry proving zero open positions;
- remains one-way tightening only.

The journal now uses canonical target-lifecycle truth for active theses, so a blocked deep target cannot remain displayed as the next executable objective when an OWNER_CAP is active.

## Publication timestamp truth

A frozen thesis owner now preserves its original exact-geometry publication timestamp separately from the current owner projection/requalification timestamp.

Dashboard presentation distinguishes:
- Owner origin geometry published
- Current owner projection published

This prevents a current projection timestamp from being misread as the original owner publication.

## Readiness wording

The 11/11-style checklist is now labeled as pre-entry conditions. It explicitly states that full prerequisite completion is not an M1 trigger and is not order permission. Sequence remains the final M1 execution gate.
