# MT5 stable 6.4.16 — Sequence 3.75: exact attached-liquidity authority

DEMO / PAPER ONLY.

## Change scope

Cloud 6.5.142 exports the exact BSL/SSL reference already selected as the zone's attached institutional liquidity. The source TF/provenance, zone geometry, grading, mitigation count and targets are unchanged.

For original-zone reaction trades, Sequence 3.75 now requires a CLOSED-M1 raid of that exact level followed by a bounded directional reclaim before the model's causal break/engulfing event. The check is fail-closed if the level, direction, source-ready timestamp, owner acquisition or bars are missing. An ordinary micro-M1 swing is not a substitute for the attached HTF liquidity.

P0/B0 records verified canonical proof only if an MT5 order was actually opened. R1/R2 use that proof only for the same zone, liquidity level, direction and owner acquisition. Re-entries do not have to sweep the same HTF liquidity again.

Three separate model confirmation chains remain unchanged. Sequence 3.74's final closed-direction M1 gate, primary core-protected stop geometry, spread guard, RR and lot sizing, target lifecycle, accepted-zone flip execution and ManagePositions remain unchanged.

## Backtest limitation

Strict canonical BSL/SSL provenance is not inferable from a generic M1 price series alone. The isolated Strategy Tester mode requires an explicit tester liquidity level.
