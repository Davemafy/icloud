# Cloud 6.5.104 — Multi-bar HTF displacement source discovery

Status: DEMO / PAPER ONLY

MT5 stable package is unchanged at 6.3.38:
- DataBridge 1.55
- DataBridge core 1.32
- Sequence EA 3.45

## Live validation that exposed the residual gap

After Cloud 6.5.103 deployed correctly, the live map still retained the remote H1
SELL source around 4259 while London price had already displaced far below it.
The new closed-H1 drift analysis was running, but no nearer H1/H4 source qualified.

The residual cause was source discovery, not reanalysis scheduling.

The Master Sniper source engine recognised:
- one-candle H1/H4 displacement/BOS; and
- liquidity-sweep rejection followed by displacement.

It did not recognise an institutional BOS delivered across a sequence of two to
four closed H1/H4 candles when no single candle individually exceeded the legacy
1.55x displacement threshold. That pattern is common during a strong London
delivery and can leave a genuine pre-impulse institutional source invisible even
though the complete H1/H4 leg is decisive.

## 6.5.104 behavior

- Adds causal 2-4 candle H1/H4 displacement-leg discovery.
- Requires a decisive net move of at least 1.80x the pre-leg HTF noise estimate.
- Requires directional body efficiency and limits opposing candle body inside the
  impulse.
- Requires the final closed HTF candle to break the preceding structural range.
- Anchors the zone to the actual pre-impulse H1/H4 source candle.
- Never uses the newest potentially forming H1/H4 candle as completed evidence.
- Records the source as MULTI_BAR_DISPLACEMENT_BOS_SOURCE and exposes
  MULTI_BAR_HTF_DISPLACEMENT as provenance.
- The normal Master Sniper qualification remains unchanged after discovery:
  genuine BSL/SSL attachment, tactical geometry, M15 health, current-price side,
  grade, target/runway safety, M1 sequence, news/spread and thesis ownership all
  remain mandatory.
- M15 still cannot create HTF location and no manual price is hard-coded.

The single-candle displacement and liquidity-sweep source models remain active.
This change adds the missing closed multi-candle impulse path rather than replacing
the existing source engine.

## Expected live effect

On the next qualifying closed-H1 reanalysis, a nearer continuation source may now
be considered if the recent London sell leg was structurally delivered across
multiple H1 candles. If that source still fails attached-liquidity or M15-health
requirements, the remote zone remains context and no replacement is forced.

Because this changes zoning outcomes, deterministic replay provenance advances to
Cloud 6.5.104.

No MT5 reinstall or reattach is required for this Cloud-only release.
