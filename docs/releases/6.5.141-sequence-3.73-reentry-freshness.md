# Cloud 6.5.141 / MT5 Stable 6.4.14 — Sequence 3.73 R1/R2 deterioration guard

## Scope

- Cloud: 6.5.141
- MT5 stable package: 6.4.14
- Sequence EA: 3.73
- DataBridge: 1.59 unchanged
- DEMO / PAPER ONLY

## Forensic trigger

The 06 Oct H1 SELL campaign on `PZ_H1_SELL_1791248400` consumed P0, R1 and R2 while the thesis had not yet received accepted M15 invalidation.

Observed executions:

- P0 SELL 4151.66, closed 4154.70
- R1 SELL 4151.88, closed 4153.54
- R2 SELL 4155.95, closed 4156.83

The former tactical SELL envelope was approximately 4145.66–4153.28. R2 therefore executed beyond the original-zone distal boundary before accepted M15 invalidation had formally completed.

Code audit found two independent R1/R2 weaknesses.

## 1. Re-entry opportunity epoch was not explicit

The campaign cap correctly limited execution to P0 + R1 + R2, but the current slot could still be built from a contact / sweep / engulfing / break associated with the preceding execution epoch.

The duplicate key was not a sufficient defense because it also contains the newest confirmation-bar timestamp. A later directional close could therefore make an old structural chain look unique enough to consume another slot.

Sequence 3.73 adds a downstream re-entry freshness invariant:

- P0 is not affected.
- If the previous campaign leg is still open but protected, both the signal anchor and structural break must be strictly newer than the prior campaign entry bar.
- If the campaign is flat, Sequence reconstructs the latest MT5 exit for this EA/symbol and uses that actual exit timestamp as the freshness floor.
- For the original-zone reacquisition family, the associated HTF-zone contact must also be strictly newer than that same execution-epoch floor.
- A missing/old event is rejected at `REENTRY_FRESHNESS`.

This does not change the underlying Model 1, Model 2, continuation or breakout definitions. It prevents one execution epoch from being recycled into the next slot.

## 2. Original-zone reacquisition could execute while still beyond the distal boundary

Accepted M15 invalidation remains the canonical thesis-failure rule. That correctly allows a temporary distal wick to recover without killing the whole thesis.

However, an original-zone reacquisition entry should not be opened while the live quote itself is still beyond the same zone's distal boundary. A valid sweep can occur outside the envelope, but the actual same-direction re-entry must first reclaim the valid side of the boundary.

Sequence 3.73 therefore applies a narrow location guard only to:

- `MASTER_SNIPER_PD_*`
- `ZONE_ENGULFING`
- `ZONE_ENGULFING_RETEST`

For BUY reacquisition, an entry below `zone_low` is blocked.
For SELL reacquisition, an entry above `zone_high` is blocked.
A small tick/point tolerance is retained.

The rejection is published as `REENTRY_LOCATION / REENTRY_ORIGINAL_ZONE_MODEL_BEYOND_DISTAL_BOUNDARY`.

## Preserved re-entry families

The distal-side guard does not classify these as original-zone reacquisition:

- causal displacement continuation (`CONTINUATION_PD_*`)
- institutional breakout (`BREAKOUT_*`)

Those families may still produce R1/R2 when their own complete, fresh post-prior-execution structure qualifies. They remain subject to the existing campaign cap, protected-swing stop, RR, target, parity, authority, spread and risk gates.

## Frozen areas

This release intentionally does not modify:

- zone generation or grading;
- P0 scanner/model logic;
- accepted-zone flip evaluation;
- ownership acquisition/release;
- P0/R1/R2 maximum count;
- risk matrix or sizing;
- protected M1 swing stop;
- minimum RR;
- objective lifecycle;
- target selection;
- `ManagePositions()`.

Regression tests require the complete `ManagePositions()` function in 3.73 to remain byte-for-byte identical to 3.72, and also require the P0 scanner and accepted-flip evaluator to remain identical.

## Operational interpretation

R1/R2 are now treated as genuine new opportunities rather than unused order slots.

A stopped trade does not automatically invalidate the HTF thesis, but the next slot must earn its own fresh structural evidence. If an original-zone model is still trading on the wrong side of the distal boundary, Sequence waits rather than repeatedly fading the same deterioration.

Fresh continuation/breakout evidence remains available without forcing price all the way back into the original HTF zone.
