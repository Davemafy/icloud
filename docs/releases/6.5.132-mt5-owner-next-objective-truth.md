## Correction

The MT5 chart overlay's `NEXT OBJECTIVE` value now uses persisted owner target-hit timestamps as the primary lifecycle truth.

Previously, the MT5 zone-render feed inferred completed targets mainly from `best_price`. If the owner lifecycle had already persisted TP1/TP2 hit timestamps but the analysis snapshot carried an older or partial `best_price`, the chart could incorrectly display a completed target as still open.

The corrected order is:

1. explicit `target1_hit_at / target2_hit_at / target3_hit_at`;
2. best-price inference only as a compatibility fallback for older lifecycle rows;
3. ownership objective cap logic remains unchanged.

This is presentation/contract reconciliation only. It does not change zone geometry, thesis ownership, M1 authority, order-flow proxy logic, risk, spread/news guards, or order execution.
