## Why this release exists

The Master Sniper zoning and ownership logic can identify a valid institutional
location correctly while the original ICT sniper pattern is not always the only
professional way to participate in the move.

Older Trade Zone research already contained three useful continuation models:
momentum pullback, VWAP-proxy reclaim and London/NY opening-range breakout/retest.
Those models were no longer wired into the current Sequence runtime after the
later ownership, parity, closed-M1 confirmation and zone-distal-stop releases.

Sequence 3.47 restores those opportunities without restoring the old loose
execution behavior.

## Strategic hierarchy

The normal hierarchy remains first:

1. ICT sniper primary
2. continuation/deep-value rescue
3. escape pullback
4. strategic alternatives:
   - London/NY opening-range breakout/retest
   - momentum pullback
   - VWAP-proxy reclaim

The alternative layer is searched only when the higher-priority valid pattern is
not available. It does not compete with or bypass an already-valid sniper entry.

## Strategic model requirements

### Momentum pullback

Requires:
- valid CONTINUATION thesis
- live institutional handoff
- recent institutional-zone interaction for first entry
- Cloud model flag enabled
- local M1 regime TREND or EXPANSION
- M1 BOS
- displacement >= configured threshold
- 30-60% impulse retracement window
- fresh M1 OB/FVG PD array inside that value window
- later CLOSED M1 same-direction rejection + micro-break
- no chase
- target + minimum RR + risk gates

### VWAP-proxy reclaim

The VWAP value is a tick-volume-weighted XAUUSD CFD proxy. It is not represented
as centralized COMEX volume or exchange VWAP.

Requires:
- valid CONTINUATION thesis
- Cloud model flag enabled
- local M1 TREND regime
- directional VWAP-proxy slope
- M1 BOS + displacement
- fresh OB/FVG PD array overlapping the VWAP reclaim band
- CLOSED M1 directional reaction + micro-break
- all normal target, RR, spread, parity and risk gates

### London/NY opening-range breakout/retest

Requires:
- valid CONTINUATION thesis
- Cloud model flag enabled
- local M1 TREND or EXPANSION regime
- completed 30-minute London or NY opening range
- directional breakout with displacement
- fresh OB/FVG PD array overlapping the broken opening-range boundary
- CLOSED M1 rejection/micro-break from that overlap
- no chase and all normal safety/risk gates

## First entry vs re-entry

Strategic first entries use a conservative 0.75 model multiplier inside the
existing thesis budget. They remain first entries, so Stable 6.3.39's corrected
full-zone distal SL floor still applies.

Strategic re-entries use the same 0.75 multiplier on the normal R1/R2 allocation
and remain subject to the existing re-entry cap and closed-M1 re-entry
confirmation. If a position is still open, it must already be protected before
another leg is considered.

No model can increase the thesis risk budget.

## Fail-closed behavior

A strategic signal is discarded if any of the following is missing:
- valid HTF/owner authority
- permitted Cloud + local regime
- real M1 structure/displacement
- fresh PD array
- closed-M1 reaction
- valid directional target
- minimum RR using the correct structural stop
- parity/safety/spread/news/snapshot requirements
- risk-sized broker-valid volume

The system must miss a trade rather than manufacture a weaker one.
