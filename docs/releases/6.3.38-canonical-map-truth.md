## DataBridge 1.55

The chart-level HTF map count is now canonical: it is rebuilt from valid `PRIMARY` records already parsed from `/mt5/zones`. Reserve geometry and invalidated flip context remain separately visible and are excluded from the primary count.

A finalized Sequence state of `AUTHORITY / PLAN_WATCH_ONLY` now renders as `CLOUD PLAN WATCH ONLY` instead of the generic `EXECUTION HOLD`.

## Renderer V662

Raw state names are no longer shown as trader-facing lifecycle labels. In particular, `ARMED` is displayed as `MAP VALID / RETEST PENDING`, while M1 handoff and thesis ownership remain separate labels.

Sequence remains 3.45 because no order logic changed. DataBridge 1.55 requires the normal installer/re-attach cycle.
