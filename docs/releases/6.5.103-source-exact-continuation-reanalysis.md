## Live problem corrected

The market-drift reanalysis introduced in 6.5.102 was correctly asking for a fresh
map, but two implementation details could keep a remote zone on screen longer than
the Master Sniper contract intends:

1. The legacy dynamic-continuation factory was intentionally fail-closed after
   source-exact zoning disabled synthetic FVG-centred geometry.
2. Dynamic continuation required a directional D1 context, so a strong H1/H4
   expansion could not promote a nearer valid continuation source while D1 was
   NEUTRAL.

Repeated drift analyses could also run several times inside one H1 candle and the
analysis-local candidate index could change a zone id even when the underlying
institutional source had not changed.

## 6.5.103 behavior

- A recent H1/H4 BOS/FVG is now a discovery trigger only.
- Final continuation geometry is rebuilt from the actual closed H1/H4 source candle.
- The normal Master Sniper qualification path remains authoritative:
  genuine BSL/SSL must already exist inside that source envelope, M15 history must
  be healthy, and the zone must remain on the correct side of live price.
- FVG never creates or widens a zone.
- D1 NEUTRAL no longer suppresses an otherwise confirmed same-direction H1/H4
  expansion. D1 remains context; H4/H1 can still identify today's tactical
  continuation battlefield.
- A candidate whose confirming HTF evidence has not closed is rejected with
  SOURCE_EVIDENCE_NOT_CLOSED.
- Zone ids are stable by institutional source identity rather than analysis-local
  candidate-list index.
- Market-drift structural reanalysis is limited to one pass per newly closed H1 bar
  while the selected map remains remote. M15/M1 execution monitoring remains live
  continuously.
- Pre-reanking source records remain lifecycle/context only. Exact publication
  samples are created only from the final visible re-ranked map, preventing the
  validation ledger from counting hidden intermediate maps as publications.

## Safety boundary

Nothing in this release authorizes a trade because price is moving fast. The same
location, M15 health, M1 sweep/MSS/BOS/displacement/value sequence, target/runway,
spread/news, risk, thesis ownership and Sequence order gates remain mandatory.

If no nearer H1/H4 source passes the full source/liquidity rules, the existing
remote zone remains valid context rather than a forced replacement.

No MT5 reinstall is required for this Cloud-only release.
